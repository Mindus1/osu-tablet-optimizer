# Modern UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** restyle every page so the app looks modern, clean and recognizably made for osu! players. Behavior stays the same; only layout, color, type and copy change (plus a dismissible notice and the skipped-list cut-off).

**Architecture:** one new module `src/ui/style.rs` holds the tokens (colors, fonts), the theme, widget style functions and a few layout helpers (`page`, `panel`, `titled`, `dot`, `ring`, `divider`, buttons, `banner`). Pages use only these, so the look lives in one place. Charts take their colors from the same tokens.

**Tech Stack:** iced 0.14 (`Theme::custom`, per-widget `.style`), Exo 2 (SIL OFL 1.1) bundled as static Latin cuts from Fontsource (`assets/fonts/`, about 44 KB each).

**Spec:** `docs/superpowers/specs/2026-10-09-osu-tablet-optimizer-design.md` (pages and their content are unchanged).

## Design

**Grounding.** The app is a companion to osu! and OpenTabletDriver. The look borrows from osu! itself: lazer's plum-tinted overlay colors, osu! pink, the hit-judgement colors as semantic tones, the approach circle as the one signature mark, and Exo 2, lazer's original UI typeface.

**Color tokens**

| Token | Hex | Role |
|---|---|---|
| `INK` | `#17131A` | window background (theme background) |
| `PANEL` | `#211B25` | sidebar and panels |
| `RAISED` | `#2C2431` | hover, selected nav, tablet surface |
| `LINE` | `#3A3140` | hairline borders and dividers |
| `TEXT` | `#F2ECF4` | text |
| `MUTED` | `#A397A8` | secondary text, labels |
| `PINK` | `#FF66AB` | the accent: primary actions, focus, active page, hit circle |
| `GREAT` | `#66CCFF` | osu!'s 300: "no clear effect" (fine), jump dots |
| `OK` | `#B3D944` | osu!'s 100: success (export saved) |
| `MEH` | `#FFCC22` | osu!'s 50: "clear effect, worth correcting", warnings |
| `MISS` | `#FF4F64` | errors, missing folders |

**Type.** Exo 2 Regular for text, SemiBold for titles, headings and big numbers. Scale: page title 28, big number 32, section heading 17, body 15, small/muted 13.

**Layout**

```
┌───────────────┬──────────────────────────────────────────────┐
│ ◯ Tablet      │ [notice banner ………………………………… Dismiss]         │
│   Optimizer   │ Title                          [sec] [PRIMARY] │
│   for osu!    │ What this page is for (muted)                 │
│               │ ┌─ panel ──────────────────────────────────┐ │
│ ◯ Replays     │ │ content                                    │ │
│   Analysis    │ └────────────────────────────────────────────┘ │
│   Area        │                                                │
│   History     │                                                │
│   Setup       │                                                │
│ ───────────── │                                                │
│ scan status   │                                                │
│ [Rescan]      │                                                │
└───────────────┴──────────────────────────────────────────────┘
```

- Left aligned throughout. Sidebar 220 px on `PANEL`, content on `INK` with 28/32 px padding.
- The active page carries a pink approach-circle ring; inactive pages are muted with no marker (hover tints `RAISED`).
- Panels: `PANEL`, 1 px `LINE` border, radius 12, no shadows. Not everything is a panel: page titles, filter rows and notes sit on `INK`.
- Buttons: primary = pink with ink text; secondary = `RAISED` with a `LINE` border; radius 8, padding 8×16. Inputs and pick lists: `INK` fill, `LINE` border, pink when focused/open, radius 8.
- Verdicts are a colored dot plus text: `GREAT` for "no clear effect", `MEH` for an effect worth correcting.
- Notices become a dismissible banner (`MEH` tint) above the page.

**Pages**

- **Replays.** Title, "Pick the plays to analyze, newest first." Actions: *Add files…*, *Analyze N selected* (primary). Filter row: period, area, search. Table panel: muted header row, divider, rows with selected ones tinted pink; footer inside the panel with the count and *Assign selected to area…*. Scan status moves to the sidebar.
- **Analysis.** Subtitle is the summary. Action: *Analyze selected again*. Metrics strip in one panel, split by vertical rules: label, big value, 90% range (same decimals as the value), verdict dot. Two titled chart panels. Skipped replays in a titled panel with "…and N more". Empty state with a *Go to Replays* button.
- **Area.** Actions: *Export full fit*, *Export capped step* (primary). Preview panel with a legend of line swatches; numbers table panel; notes muted. The export result shows as a green (saved) or red (failed) banner. Reasons the page can't show a suggestion get an empty-state panel.
- **History.** Action: the metric pick list. Chart panel stretching to the page width, dates under it and the note. Areas panel: dot, name input, size, since, summary, dividers between rows.
- **Setup.** One column of titled panels (osu! folders, OpenTabletDriver, Tablet, Players, Analysis), at most 760 px wide; missing folders in `MISS`.

**Charts.** Scatter dots `GREAT` at 35% alpha with the hit circle in `PINK`; polar ring `LINE` and outline `PINK`; area preview tablet `RAISED`, current `MUTED`, capped solid and full dashed `PINK`; trend colors per area `PINK, GREAT, OK, MEH, #B58CFF, #FF9A52`, unknown `MUTED`. Labels `MUTED` 13 px in Exo 2.

## Global Constraints

- No behavior changes beyond: dismissible notice, skipped list "…and N more", export banner success/failure, matching decimals. Core untouched.
- README credits Exo 2 (OFL); `assets/fonts/OFL.txt` ships with the fonts.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- Non-Latin player names and map titles: the Latin cut falls back to system fonts per glyph.
- Long map titles must not push the table columns off screen.
- Every state of every page: empty, scanning, outdated analysis, relative-mode profile, no OTD, export saved/failed.
