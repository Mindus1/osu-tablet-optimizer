# History Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** the area history. It shows over time whether a new tablet area helped:
- **Snapshots:** whenever OpenTabletDriver's area for the selected profile differs from the last one logged, it is logged with `since = settings.json` modified time. This runs at launch, before each scan, and when the OTD folder or profile changes.
- **Tagging:** a replay belongs to the last snapshot whose `since` is not after the replay's time. Older replays are *unknown*. Replays the user assigned by hand keep that area.
- **Per-replay numbers:** each analyzed replay records its overshoot, rotation, horizontal ÷ vertical, RMS distance from the circle's center (radii) and number of usable jumps.
- **History page:** list of areas (renamable, color, since, replays, mean of the chosen number) and a trend chart of the chosen number, one point per replay, colored by area.
- **Replays page:** an *Area* column, an area filter and *Assign selected to area…*.

**Architecture:**
- **Core `fit` (tested):** `measure(samples, settings) -> Option<Metrics>`. It fits the gain alone, without the edge-stop term (see Decisions).
- **Core `history` (tested):** `History { snapshots, replays, assigned }` saved as `history.json`: `observe`, `snapshot_of`, `assign`, `record`, `points`, plus `average` and `chart_range` for the page.
- **Core `otd`:** `OtdSettings::saved_at_ms`, the settings file's modified time.
- **Core `aim`:** `Report::measured`, the per-replay entries. `hits::replay_samples` also returns the replay's header (for its time).
- **Core `storage`:** `set_aside` moves from `config` (now shared by config and history).
- **UI:** `App` loads/saves the history, logs snapshots in `reload_otd`, records after each analysis. New `ui::history` page and `charts::Trend`. `ui::replays` gets the column, filter and assign list.

**Tech Stack:** iced 0.14 (canvas, `pick_list`, `text_input`), serde_json, chrono.

**Spec:** `docs/superpowers/specs/2026-10-09-osu-tablet-optimizer-design.md`

## Global Constraints

- General-purpose: nothing from the test machine (tablet, area, player, paths) in code or defaults.
- `settings.json` is only read. Nothing in OTD's folder is written by this feature.
- Chart data is computed in core and tested. Canvas drawing stays in the UI and is not unit-tested.
- `history.json` lives next to `config.json` (`storage::app_dir()`). A history that can't be read is moved aside (`history.json.bad`), never overwritten.
- Commits: Conventional Commits ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- **First run, or OTD settings saved recently for an unrelated reason:** `since` is the file's modified time, so earlier replays are *unknown* (gray), as the spec says. *Assign selected to area…* fixes it by hand. Pinned by `replays_belong_to_the_last_area_saved_before_them` (Task 2).
- **Going back to an earlier area (A → B → A):** logged as a new snapshot, so the third period is its own series. Pinned by `only_area_changes_are_logged` (Task 2).
- **A metric that isn't finite** (degenerate replay): serde_json writes NaN as `null` and then can't read the whole file back. `measure` returns `None` instead. Pinned by `measure_rejects_numbers_json_cannot_hold` (Task 1).
- **Hand-edited or damaged `history.json`:** an assignment to a missing snapshot falls back to the date (`assignment_to_a_missing_area_falls_back_to_the_date`, Task 2); unparsable files are set aside with a notice (`corrupt_history_is_an_error`, Task 2, plus `App::new`).
- **Outlier replays squashing the chart:** the value range covers the 5–95% quantiles plus the ideal value; outliers sit on the edge. Pinned by `chart_range_leaves_out_outliers_but_shows_the_ideal` (Task 2).

## Decisions

- **Per-replay numbers come from the gain alone (4 unknowns, no edge stop).** Probe on the test machine's last 400 replays (median 98 usable jumps): the full 5-unknown fit per replay spread overshoot from −11.3% to +5.9% (5–95%), because one map's jumps are often too alike in length to separate a wrong size from stopping at the edge. The gain-only fit spread −3.8% to +1.3%. Rotation and horizontal ÷ vertical aren't affected by that collinearity. Edge stopping therefore counts as a little undershoot in the history; the page says so.
- **A replay needs 20 usable jumps** for history numbers (5% of the probed replays had fewer than 37).
- **Exporting a preset logs nothing.** The area changes when the user applies it in OTD, which saves `settings.json`; the next launch, rescan or profile change logs it with that time.
- **Names:** empty until the user types one; the UI shows the size and rotation (`80 × 45 mm, 0°`) until then.

After `suggest`:

```rust
// One replay's numbers, from the gain alone: a single map's jumps are often too alike in length to
// tell a wrong area size from stopping at the circle's edge, so edge stopping shows up as a little
// undershoot here. None when the replay has too few jumps or a number isn't finite (JSON can't
// hold it).
pub fn measure(samples: &[Sample], settings: &Settings) -> Option<Metrics> {
    let usable: Vec<Sample> = samples
        .iter()
        .copied()
        .filter(|sample| is_usable(sample, settings))
        .collect();
    if usable.len() < MIN_REPLAY_SAMPLES {
        return None;
    }
    let gain = Normal::of(&usable).gain()?;
    let squared: f64 = usable
        .iter()
        .map(|sample| {
            let (ex, ey) = (
                sample.actual.0 - sample.intended.0,
                sample.actual.1 - sample.intended.1,
            );
            (ex * ex + ey * ey) / (sample.radius * sample.radius)
        })
        .sum();
    let metrics = Metrics {
        samples: usable.len(),
        overshoot: overshoot(&gain),
        rotation_bias: rotation_bias(&gain),
        axis_ratio: axis_ratio(&gain),
        error: (squared / usable.len() as f64).sqrt(),
    };
    [
        metrics.overshoot,
        metrics.rotation_bias,
        metrics.axis_ratio,
        metrics.error,
    ]
    .iter()
    .all(|value| value.is_finite())
    .then_some(metrics)
}
```

```rust
use std::collections::HashMap;
use std::fmt;
use std::fs;
use std::path::{Path, PathBuf};

use anyhow::{Context, Result};
use serde::{Deserialize, Serialize};

use crate::core::fit::{Mapping, Metrics};
use crate::core::storage;

// The chart covers the points between these quantiles; outliers sit on its edge.
const RANGE_QUANTILE: f64 = 0.05;
const RANGE_MARGIN: f64 = 0.15;
// Keeps a single value (or several equal ones) off the chart's edge.
const MIN_RANGE_MARGIN: f64 = 0.01;

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct Snapshot {
    // Empty until the user names it.
    pub name: String,
    pub mapping: Mapping,
    // When OpenTabletDriver saved the settings holding this area (ms since the Unix epoch).
    pub since_ms: i64,
}

#[derive(Debug, Clone, Copy, PartialEq, Serialize, Deserialize)]
pub struct Entry {
    pub played_at_ms: i64,
    pub metrics: Metrics,
}

#[derive(Debug, Clone, PartialEq, Default, Serialize, Deserialize)]
#[serde(default)]
pub struct History {
    // In the order they were logged and never removed, so an index names an area for good.
    pub snapshots: Vec<Snapshot>,
    replays: HashMap<PathBuf, Entry>,
    // Areas the user picked by hand.
    assigned: HashMap<PathBuf, usize>,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
pub enum Metric {
    #[default]
    Overshoot,
    Rotation,
    AxisRatio,
    Error,
}

#[derive(Debug, Clone, Copy, PartialEq)]
pub struct Point {
    pub played_at_ms: i64,
    pub snapshot: Option<usize>,
    pub value: f64,
    pub samples: usize,
}

impl Metric {
    pub const ALL: [Metric; 4] = [
        Metric::Overshoot,
        Metric::Rotation,
        Metric::AxisRatio,
        Metric::Error,
    ];

    pub fn of(self, metrics: &Metrics) -> f64 {
        match self {
            Metric::Overshoot => metrics.overshoot,
            Metric::Rotation => metrics.rotation_bias,
            Metric::AxisRatio => metrics.axis_ratio,
            Metric::Error => metrics.error,
        }
    }

    // The value when aim matches the area perfectly.
    pub fn ideal(self) -> f64 {
        match self {
            Metric::AxisRatio => 1.0,
            Metric::Overshoot | Metric::Rotation | Metric::Error => 0.0,
        }
    }
}

impl fmt::Display for Metric {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        f.write_str(match self {
            Metric::Overshoot => "Overshoot",
            Metric::Rotation => "Rotation",
            Metric::AxisRatio => "Horizontal ÷ vertical",
            Metric::Error => "Distance from the center",
        })
    }
}

impl History {
    // A missing file is an empty history.
    pub fn load(path: &Path) -> Result<History> {
        if !path.exists() {
            return Ok(History::default());
        }
        let text =
            fs::read_to_string(path).with_context(|| format!("reading {}", path.display()))?;
        serde_json::from_str(&text).with_context(|| format!("parsing {}", path.display()))
    }

    pub fn save(&self, path: &Path) -> Result<()> {
        storage::write_atomic(path, &serde_json::to_vec(self)?)
    }

    // Logs OpenTabletDriver's area when it differs from the last one logged; true when it did.
    pub fn observe(&mut self, mapping: Mapping, saved_at_ms: i64) -> bool {
        if self
            .snapshots
            .last()
            .is_some_and(|last| last.mapping == mapping)
        {
            return false;
        }
        self.snapshots.push(Snapshot {
            name: String::new(),
            mapping,
            since_ms: saved_at_ms,
        });
        true
    }

    // The area a replay was played with: the user's pick, else the last one saved before it was
    // played. None when it was played before the first logged area.
    pub fn snapshot_of(&self, path: &Path, played_at_ms: i64) -> Option<usize> {
        let assigned = self
            .assigned
            .get(path)
            .copied()
            .filter(|&index| index < self.snapshots.len());
        assigned.or_else(|| {
            self.snapshots
                .iter()
                .enumerate()
                .filter(|(_, snapshot)| snapshot.since_ms <= played_at_ms)
                .max_by_key(|&(index, snapshot)| (snapshot.since_ms, index))
                .map(|(index, _)| index)
        })
    }

    // None hands the replays back to their date.
    pub fn assign(&mut self, paths: impl IntoIterator<Item = PathBuf>, snapshot: Option<usize>) {
        for path in paths {
            match snapshot {
                Some(index) => {
                    self.assigned.insert(path, index);
                }
                None => {
                    self.assigned.remove(&path);
                }
            }
        }
    }

    pub fn record(&mut self, measured: &[(PathBuf, Entry)]) {
        self.replays.extend(measured.iter().cloned());
    }

    // Every recorded replay, oldest first.
    pub fn points(&self, metric: Metric) -> Vec<Point> {
        let mut points: Vec<Point> = self
            .replays
            .iter()
            .map(|(path, entry)| Point {
                played_at_ms: entry.played_at_ms,
                snapshot: self.snapshot_of(path, entry.played_at_ms),
                value: metric.of(&entry.metrics),
                samples: entry.metrics.samples,
            })
            .collect();
        points.sort_by_key(|point| point.played_at_ms);
        points
    }
}

// How many replays one area has, and their mean weighted by usable jumps so short replays
// count less.
pub fn average(points: &[Point], snapshot: Option<usize>) -> Option<(usize, f64)> {
    let from: Vec<&Point> = points
        .iter()
        .filter(|point| point.snapshot == snapshot)
        .collect();
    let samples: usize = from.iter().map(|point| point.samples).sum();
    if samples == 0 {
        return None;
    }
    let total: f64 = from
        .iter()
        .map(|point| point.value * point.samples as f64)
        .sum();
    Some((from.len(), total / samples as f64))
}

// The chart's value range: most points and the ideal value, with a margin.
pub fn chart_range(points: &[Point], ideal: f64) -> (f64, f64) {
    let mut values: Vec<f64> = points.iter().map(|point| point.value).collect();
    values.sort_by(f64::total_cmp);
    let at = |q: f64| {
        let index = (values.len().saturating_sub(1) as f64 * q).round() as usize;
        values.get(index).copied().unwrap_or(ideal)
    };
    let low = at(RANGE_QUANTILE).min(ideal);
    let high = at(1.0 - RANGE_QUANTILE).max(ideal);
    let margin = ((high - low) * RANGE_MARGIN).max(MIN_RANGE_MARGIN);
    (low - margin, high + margin)
}
```

```rust
impl<Message> canvas::Program<Message> for Trend {
    type State = ();

    fn draw(
        &self,
        _state: &(),
        renderer: &Renderer,
        theme: &Theme,
        bounds: Rectangle,
        _cursor: mouse::Cursor,
    ) -> Vec<Geometry> {
        let mut frame = Frame::new(renderer, bounds.size());
        let (low, high) = self.range;
        let y = |value: f64| ((high - value.clamp(low, high)) / (high - low)) as f32 * bounds.height;
        let first = self.points.first().map_or(0, |point| point.played_at_ms);
        let last = self.points.last().map_or(0, |point| point.played_at_ms);

        let x = |ms: i64| TREND_GUTTER + (ms - first) as f32 / span * width;

        frame.stroke(
            &Path::line(
                Point::new(TREND_GUTTER, y(self.ideal)),
                Point::new(bounds.width, y(self.ideal)),
            ),
            Stroke::default()
                .with_color(theme.extended_palette().background.strong.color)
                .with_width(1.0),
        );
```

```rust
    }

// A snapshot's name, or its size and rotation until it has one.
pub fn area_label(history: &History, area: Option<usize>) -> String {
    match area.and_then(|index| history.snapshots.get(index)) {
        Some(snapshot) if !snapshot.name.is_empty() => snapshot.name.clone(),
        Some(snapshot) => describe(&snapshot.mapping),
        None => "unknown".to_string(),
    }
}

// One line per area; the unknown area only when it has replays.
fn area_row<'a>(
    history: &'a History,
    area: Option<usize>,
    points: &[Point],
    metric: Metric,
) -> Option<Element<'a, app::Message>> {
    let average = history::average(points, area);
    let summary = match average {
        Some((replays, mean)) => format!("{replays} replays, mean {}", format_value(metric, mean)),
        None => "no analyzed replays".to_string(),
    };
    let swatch = text("●").color(charts::area_color(area));
    let Some(index) = area else {
        return average.map(|_| {
            row![
                swatch,
                text("Before the first logged area").width(460),
                text(summary)
            ]
            .spacing(12)
            .into()
        });
    };
    let snapshot = &history.snapshots[index];
    Some(
        row![
            swatch,
            text_input("Name this area", &snapshot.name)
                .on_input(move |name| app::Message::History(Message::Rename(index, name)))
                .width(180),
            text(describe(&snapshot.mapping)).width(160),
            text(format!("since {}", replays::played_at(snapshot.since_ms))).width(100),
            text(summary),
        ]
        .spacing(12)
        .align_y(Center)
        .into(),
    )
}

    )

fn format_value(metric: Metric, value: f64) -> String {

        Metric::Overshoot => format!("{:+.1}%", value * 100.0),
        Metric::Rotation => format!("{value:+.2}°"),
        Metric::AxisRatio => format!("{value:.3}"),
        Metric::Error => format!("{value:.2} radii"),
    }
```
