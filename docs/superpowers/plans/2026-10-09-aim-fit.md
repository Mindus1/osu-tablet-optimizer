# Aim Fit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `core::fit` turns the aim samples of several replays into a suggested OpenTabletDriver area: width, height and rotation, each with a 90% interval. It gives a full-correction value and a capped step, plus human-readable metrics (overshoot, rotation bias, axis ratio, shear).

**Architecture:** One module, `src/core/fit.rs`.
- **Filter:** keep samples with `|intended| ≥ 3r` and `|actual − intended| ≤ 3r`. Drop non-finite samples and radius ≤ 0.
- **Fit:** least squares for `actual = B·intended + k·direction(intended)` (5 unknowns, hand-written Gaussian elimination). `B` is the player's gain. `k` absorbs edge-stopping, which doesn't grow with jump distance, so it separates from a size error.
- **OTD transform:** OTD maps tablet mm to display px as `M = diag(Dw/w, Dh/h)·R(−θ)`. That's verified against `AbsoluteOutputMode.CalculateTransformation` in OTD 0.6.x, where `Matrix3x2.CreateRotation(−θ)` is applied before the per-axis scale.
- **Correction:** the corrected mapping is `M' = B⁻¹·M`. From its rows, `w' = Dw/|row₀|` and `h' = Dh/|row₁|`, `θ'` is the mean row angle, and the leftover row skew is the shear (reported only). A player whose moves come out rotated by +φ gets `θ' = θ + φ`, pinned by a test.
- **Intervals:** a 200-round bootstrap over **replays** (seeded splitmix64, so results are deterministic) gives 90% intervals. Each replay's least-squares sums are computed once, and a round just adds them up.
- **Keep:** a parameter whose interval contains its current value keeps it.
- **Capped step:** at most ±3% size and ±2° rotation per step (configurable through `Settings`).

**Why replays and not hits:** a prototype bootstrapped single hits. On the test machine's 300 most recent replays, the intervals of two interleaved halves (even/odd replays) didn't overlap: width 98.03 [97.74, 98.34] versus 97.14 [96.79, 97.45]. Aim varies between sessions, so hit-level intervals were far too narrow. This answers the spec's "cluster by replay if CIs look too tight", and so a suggestion needs at least 5 replays and 50 usable samples.

**Measured on the test machine** (300 most recent standard replays, generic 100×56.25 mm → 1920×1080 mapping): 34,208 usable samples.
- overshoot −2.25% [−2.88%, −1.65%]
- rotation bias +0.41° [0.34, 0.49]
- axis ratio 0.998 [0.995, 1.000], so it keeps the aspect
- suggested width 97.6 [96.9, 98.4] and height 55.04 [54.71, 55.33]
- shear −0.30°

## Review Focus

- **Non-finite samples** (NaN or infinity from a bad replay or a broken DA setting): left out, never poisoning the fit. Pinned by `non_finite_samples_are_left_out` (Task 1).
- **A current rotation near ±180°:** the corrected rotation stays continuous (179° + 2° = 181°, not −179°). Pinned by `rotation_wraps_around_180_degrees` (Task 1).
- **An invalid OTD mapping** (zero or non-finite size from a broken settings file): no suggestion rather than NaN numbers. Pinned by `invalid_mapping_gives_no_suggestion` (Task 1).
- **Jumps all along one line:** a singular system gives no suggestion rather than garbage. Pinned by `jumps_along_one_line_give_no_suggestion` (Task 1).
- **A single replay:** not enough evidence for a tablet change, so no suggestion. Pinned by `one_replay_is_not_enough` (Task 1).

use crate::core::hits::Sample;

// ponytail: fixed statistics knobs; expose them in Setup if users ask.
const MIN_SAMPLES: usize = 50;
// The bootstrap resamples whole replays (aim varies between sessions), which needs a few of them.
const MIN_REPLAYS: usize = 5;
const BOOTSTRAP_ROUNDS: usize = 200;
// Two-sided 90% interval.
const TAIL: f64 = 0.05;

type Mat2 = [[f64; 2]; 2];

#[derive(Debug, Clone, Copy, PartialEq)]
pub struct Settings {
    pub min_jump_radii: f64,
    pub max_error_radii: f64,
    pub max_size_step: f64,
    pub max_rotation_step_deg: f64,
}

impl Default for Settings {
    fn default() -> Self {
        Settings {
            min_jump_radii: 3.0,
            max_error_radii: 3.0,
            max_size_step: 0.03,
            max_rotation_step_deg: 2.0,
        }
    }
}

// OpenTabletDriver's absolute mapping: tablet area (mm, degrees) onto a display area (px).
#[derive(Debug, Clone, Copy, PartialEq)]
pub struct Mapping {
    pub area_width: f64,
    pub area_height: f64,
    pub rotation: f64,
    pub display_width: f64,
    pub display_height: f64,
}

#[derive(Debug, Clone, Copy, PartialEq)]
pub struct Estimate {
    pub value: f64,
    pub low: f64,
    pub high: f64,
}

impl Estimate {
    fn new(value: f64, rounds: impl Iterator<Item = f64>) -> Estimate {
        let mut rounds: Vec<f64> = rounds.collect();
        if rounds.is_empty() {
            return Estimate {
                value,
                low: value,
                high: value,
            };
        }
        rounds.sort_by(f64::total_cmp);
        let at = |q: f64| rounds[((rounds.len() - 1) as f64 * q).round() as usize];
        Estimate {
            value,
            low: at(TAIL),
            high: at(1.0 - TAIL),
        }
    }

    pub fn contains(&self, x: f64) -> bool {
        self.low <= x && x <= self.high
    }
}

#[derive(Debug, Clone, Copy, PartialEq)]
pub struct Suggestion {
    pub replays: usize,
    pub samples: usize,
    // How far the cursor travels per intended distance, minus one: +0.05 = 5% overshoot.
    pub overshoot: Estimate,
    // Angle (degrees) by which actual moves are turned against intended ones, x towards y.
    pub rotation_bias: Estimate,
    // Horizontal gain over vertical gain.
    pub axis_ratio: Estimate,
    pub width: Estimate,
    pub height: Estimate,
    pub rotation: Estimate,
    // Skew OTD cannot express; left over after the area fit (degrees).
    pub shear: f64,
    // Each parameter keeps its current value when its interval contains it.
    pub full: Mapping,
    pub capped: Mapping,
}

// Least-squares sums for actual = gain · intended + edge_stop · direction(intended). The
// edge-stop term soaks up stopping at the circle's edge, which does not grow with jump distance;
// a wrong area size does, so the two separate when jump distances vary.
#[derive(Debug, Clone, Copy, Default)]
struct Normal {
    a: [[f64; 5]; 5],
    b: [f64; 5],
}

impl Normal {
    fn of(samples: &[Sample]) -> Normal {
        let mut normal = Normal::default();
        for sample in samples {
            let (ux, uy) = sample.intended;
            let (vx, vy) = sample.actual;
            let length = ux.hypot(uy);
            let rows = [
                ([ux, uy, 0.0, 0.0, ux / length], vx),
                ([0.0, 0.0, ux, uy, uy / length], vy),
            ];
            for (row, value) in rows {
                for i in 0..5 {
                    for j in 0..5 {
                        normal.a[i][j] += row[i] * row[j];
                    }
                    normal.b[i] += row[i] * value;
                }
            }
        }
        normal
    }

    fn add(&mut self, other: &Normal) {
        for i in 0..5 {
            for j in 0..5 {
                self.a[i][j] += other.a[i][j];
            }
            self.b[i] += other.b[i];
        }
    }

    fn gain(&self) -> Option<Mat2> {
        let [b00, b01, b10, b11, _edge_stop] = solve(self.a, self.b)?;
        Some([[b00, b01], [b10, b11]])
    }
}

// One sample list per replay.
pub fn suggest(
    replays: &[Vec<Sample>],
    current: Mapping,
    settings: &Settings,
) -> Option<Suggestion> {
    if !is_valid(&current) {
        return None;
    }
    let groups: Vec<(usize, Normal)> = replays
        .iter()
        .map(|samples| {
            let usable: Vec<Sample> = samples
                .iter()
                .copied()
                .filter(|sample| is_usable(sample, settings))
                .collect();
            (usable.len(), Normal::of(&usable))
        })
        .filter(|(count, _)| *count > 0)
        .collect();
    let samples: usize = groups.iter().map(|(count, _)| count).sum();
    if groups.len() < MIN_REPLAYS || samples < MIN_SAMPLES {
        return None;
    }
    let mut total = Normal::default();
    for (_, normal) in &groups {
        total.add(normal);
    }
    let gain = total.gain()?;
    let (mapping, shear) = corrected(current, &gain)?;

    let mut rng = Rng(samples as u64);
    let rounds: Vec<(Mat2, Mapping)> = (0..BOOTSTRAP_ROUNDS)
        .filter_map(|_| {
            let mut resample = Normal::default();
            for _ in 0..groups.len() {
                resample.add(&groups[rng.below(groups.len())].1);
            }
            let matrix = resample.gain()?;
            Some((matrix, corrected(current, &matrix)?.0))
        })
        .collect();
    let estimate = |value: f64, round: fn(&(Mat2, Mapping)) -> f64| {
        Estimate::new(value, rounds.iter().map(round))
    };

    let width = estimate(mapping.area_width, |(_, m)| m.area_width);
    let height = estimate(mapping.area_height, |(_, m)| m.area_height);
    let rotation = estimate(mapping.rotation, |(_, m)| m.rotation);
    let full = Mapping {
        area_width: keep(width, current.area_width),
        area_height: keep(height, current.area_height),
        rotation: keep(rotation, current.rotation),
        ..current
    };
    let size_step = |full: f64, now: f64| {
        now * (full / now).clamp(1.0 - settings.max_size_step, 1.0 + settings.max_size_step)
    };
    let capped = Mapping {
        area_width: size_step(full.area_width, current.area_width),
        area_height: size_step(full.area_height, current.area_height),
        rotation: current.rotation
            + (full.rotation - current.rotation).clamp(
                -settings.max_rotation_step_deg,
                settings.max_rotation_step_deg,
            ),
        ..current
    };

    Some(Suggestion {
        replays: groups.len(),
        samples,
        overshoot: estimate(overshoot(&gain), |(m, _)| overshoot(m)),
        rotation_bias: estimate(rotation_bias(&gain), |(m, _)| rotation_bias(m)),
        axis_ratio: estimate(axis_ratio(&gain), |(m, _)| axis_ratio(m)),
        width,
        height,
        rotation,
        shear,
        full,
        capped,
    })
}

fn is_valid(mapping: &Mapping) -> bool {
    let sizes = [
        mapping.area_width,
        mapping.area_height,
        mapping.display_width,
        mapping.display_height,
    ];
    sizes.iter().all(|size| size.is_finite() && *size > 0.0) && mapping.rotation.is_finite()
}

fn is_usable(sample: &Sample, settings: &Settings) -> bool {
    let (ux, uy) = sample.intended;
    let (vx, vy) = sample.actual;
    sample.radius > 0.0
        && ux.hypot(uy) >= settings.min_jump_radii * sample.radius
        && (vx - ux).hypot(vy - uy) <= settings.max_error_radii * sample.radius
}

fn keep(estimate: Estimate, current: f64) -> f64 {
    if estimate.contains(current) {
        current
    } else {
        estimate.value
    }
}

// OTD maps tablet mm to display px as diag(Dw/w, Dh/h) · R(−θ) (AbsoluteOutputMode). The mapping
// that cancels the player's gain is gain⁻¹ · that; its rows give back width, height and angle.
fn corrected(current: Mapping, gain: &Mat2) -> Option<(Mapping, f64)> {
    let theta = current.rotation.to_radians();
    let (sin, cos) = theta.sin_cos();
    let otd = [
        [
            current.display_width / current.area_width * cos,
            current.display_width / current.area_width * sin,
        ],
        [
            -current.display_height / current.area_height * sin,
            current.display_height / current.area_height * cos,
        ],
    ];
    let [row_x, row_y] = mul(&inverse(gain)?, &otd);
    let angle_x = row_x[1].atan2(row_x[0]).to_degrees();
    let angle_y = (-row_y[0]).atan2(row_y[1]).to_degrees();
    let shear = wrap_degrees(angle_y - angle_x);
    let angle = angle_x + shear / 2.0;
    Some((
        Mapping {
            area_width: current.display_width / row_x[0].hypot(row_x[1]),
            area_height: current.display_height / row_y[0].hypot(row_y[1]),
            rotation: current.rotation + wrap_degrees(angle - current.rotation),
            ..current
        },
        shear,
    ))
}

fn overshoot(gain: &Mat2) -> f64 {
    determinant(gain).abs().sqrt() - 1.0
}

fn rotation_bias(gain: &Mat2) -> f64 {
    (gain[1][0] - gain[0][1])
        .atan2(gain[0][0] + gain[1][1])
        .to_degrees()
}

fn axis_ratio(gain: &Mat2) -> f64 {
    gain[0][0].hypot(gain[1][0]) / gain[0][1].hypot(gain[1][1])
}

fn determinant(m: &Mat2) -> f64 {
    m[0][0] * m[1][1] - m[0][1] * m[1][0]
}

fn inverse(m: &Mat2) -> Option<Mat2> {
    let det = determinant(m);
    if det.abs() < 1e-12 {
        return None;
    }
    Some([
        [m[1][1] / det, -m[0][1] / det],
        [-m[1][0] / det, m[0][0] / det],
    ])
}

fn mul(a: &Mat2, b: &Mat2) -> Mat2 {
    let cell = |i: usize, j: usize| a[i][0] * b[0][j] + a[i][1] * b[1][j];
    [[cell(0, 0), cell(0, 1)], [cell(1, 0), cell(1, 1)]]
}

fn wrap_degrees(angle: f64) -> f64 {
    (angle + 180.0).rem_euclid(360.0) - 180.0
}

// Gaussian elimination with partial pivoting; None when the system is (near) singular.
fn solve<const N: usize>(mut a: [[f64; N]; N], mut b: [f64; N]) -> Option<[f64; N]> {
    let scale = a.iter().flatten().fold(0.0_f64, |max, x| max.max(x.abs()));
    for col in 0..N {
        let pivot = (col..N).max_by(|&i, &j| a[i][col].abs().total_cmp(&a[j][col].abs()))?;
        if a[pivot][col].abs() <= scale * 1e-12 {
            return None;
        }
        a.swap(col, pivot);
        b.swap(col, pivot);
        for row in col + 1..N {
            let factor = a[row][col] / a[col][col];
            let pivot_row = a[col];
            for (x, p) in a[row][col..].iter_mut().zip(&pivot_row[col..]) {
                *x -= factor * p;
            }
            b[row] -= factor * b[col];
        }
    }
    let mut x = [0.0; N];
    for row in (0..N).rev() {
        let rest: f64 = (row + 1..N).map(|k| a[row][k] * x[k]).sum();
        x[row] = (b[row] - rest) / a[row][row];
    }
    Some(x)
}

// splitmix64, seeded from the data: the same samples always give the same intervals.
struct Rng(u64);

impl Rng {
    fn below(&mut self, n: usize) -> usize {
        self.0 = self.0.wrapping_add(0x9E37_79B9_7F4A_7C15);
        let mut z = self.0;
        z = (z ^ (z >> 30)).wrapping_mul(0xBF58_476D_1CE4_E5B9);
        z = (z ^ (z >> 27)).wrapping_mul(0x94D0_49BB_1331_11EB);
        ((z ^ (z >> 31)) % n as u64) as usize
    }
}
