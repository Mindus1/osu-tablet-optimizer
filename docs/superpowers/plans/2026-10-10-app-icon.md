# App Icon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** the README logo (`docs/images/logo.svg`) becomes the app's icon on every platform, then release v0.2.2.

**Architecture:**
- **Assets** (`assets/icon/`), rendered once from the SVG with a headless browser (transparent background):
  - `icon.ico`: 16, 24, 32, 48, 64, 128, 256 px as PNG entries (Windows exe).
  - `AppIcon.icns`: 16 to 1024 px as PNG entries, with Apple's ~10% margin around the tile (macOS bundle).
  - `icon-128.rgba`: 128 × 128 raw RGBA pixels for the window icon, so no image decoder is needed at runtime.
  - `assets/linux/osu-tablet-optimizer.png` (256 px) and `osu-tablet-optimizer.desktop`.
  - `assets/macos/Info.plist` with a `VERSION` placeholder.
- **Windows exe:** `build.rs` embeds `icon.ico` with `winresource` (Windows-only build dependency; it finds the SDK's resource compiler).
- **Window icon (all platforms):** `window::Settings::icon` from the raw pixels; on Linux the Wayland app id is `osu-tablet-optimizer`, matching the `.desktop` file.
- **Packaging:** `.github/package.sh` (called by the release workflow): Windows renames the exe; macOS builds `osu! Tablet Optimizer.app` (binary, `Info.plist`, `AppIcon.icns`), signs it ad hoc and tars it; Linux tars the binary with the `.desktop` file and icon.

**Spec:** `docs/superpowers/specs/2026-10-09-osu-tablet-optimizer-design.md` (release builds for Windows, Linux, macOS).

## Global Constraints

- No new runtime dependencies. `winresource` only as a Windows build dependency.
- Release workflow refuses tags whose version differs from `Cargo.toml`.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- Release packaging can only fail on the runners: a temporary workflow on this branch runs `.github/package.sh` on macOS and Linux runners and lists the archives before anything is tagged; it is deleted before merging.
- Non-Windows builds (CI on Linux) must not touch `winresource`.
