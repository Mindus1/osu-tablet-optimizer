# App Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A runnable iced window with the sidebar navigation (Replays / Analysis / Area / History / Setup), PR checks in CI, and a tag-triggered 3-OS release workflow.

**Architecture:** Single binary crate. `src/main.rs` boots iced, and `src/app.rs` holds the state (current page), the message and update/view. Pages show only their title for now; each page gets its own `src/ui/<page>.rs` in the feature that gives it content. `core/config.rs` moves to feature 7 (Replays + Setup pages), its first consumer: before that, core functions take paths as parameters, and an unused config would be scaffolding (CLAUDE.md).

**Tech Stack:** Rust stable (edition 2024), iced 0.14, GitHub Actions (`dtolnay/rust-toolchain`, `Swatinem/rust-cache`, `gh` CLI).

**Spec:** `docs/superpowers/specs/2026-10-09-osu-tablet-optimizer-design.md`

## Global Constraints

- Crate name `osu-tablet-optimizer`, version `0.0.0` (the first release bumps it to 0.1.0), `publish = false`, edition 2024.
- iced `0.14`. No other dependencies in this feature.
- Platforms: Windows + Linux + macOS.
- UI language: English only. Sidebar order: Replays / Analysis / Area / History / Setup.
- No hardcoded user paths, tablets, names or resolutions.
- Comments only for a non-obvious *why*. No doc comments that restate signatures.
- CI: PR checks (fmt/clippy/test) on Linux, for PRs into `dev` and `main`. Release: tag `v*` → Windows/Linux/macOS builds → GitHub release.
- Commits: Conventional Commits, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- The Linux CI build fails on a missing system library (`pkg-config` error). Expected: green without apt packages, because winit/wgpu load X11/Wayland/Vulkan at runtime. Pinned by the PR check in Task 4.
- The Windows release `.exe` opens an extra console window. Expected: no console, via `windows_subsystem = "windows"` in release builds. Pinned by the release-binary launch check in Task 1.
- Linux/macOS binaries downloaded from the release aren't executable. Expected: they ship in `.tar.gz` so the exec bit survives. Pinned by the archive listing in Task 4.
- A test or pre-release tag shows up as the "Latest" release. Expected: tags containing `-` are published as pre-releases. Pinned by the throwaway-tag check in Task 4.
- `cargo build --locked` fails in CI because `Cargo.lock` isn't committed. Expected: the lockfile is committed (binary crate). Pinned by Task 1's commit and the CI run in Task 4.

```rust
use iced::widget::{button, column, container, row, text};
use iced::{Element, Fill, Theme};

#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
pub enum Page {
    #[default]
    Replays,
    Analysis,
    Area,
    History,
    Setup,
}

impl Page {
    const ALL: [Page; 5] = [
        Page::Replays,
        Page::Analysis,
        Page::Area,
        Page::History,
        Page::Setup,
    ];

    fn label(self) -> &'static str {
        match self {
            Page::Replays => "Replays",
            Page::Analysis => "Analysis",
            Page::Area => "Area",
            Page::History => "History",
            Page::Setup => "Setup",
        }
    }
}

#[derive(Debug, Clone)]
pub enum Message {
    Navigate(Page),
}

#[derive(Default)]
pub struct App {
    page: Page,
}

impl App {
    pub fn update(&mut self, message: Message) {
        match message {
            Message::Navigate(page) => self.page = page,
        }
    }

    pub fn view(&self) -> Element<'_, Message> {
        let nav = Page::ALL.map(|page| {
            let style = if page == self.page {
                button::primary
            } else {
                button::text
            };
            button(page.label())
                .width(Fill)
                .style(style)
                .on_press(Message::Navigate(page))
                .into()
        });
        let sidebar = column(nav).spacing(4).padding(8).width(160);
        let content = container(text(self.page.label()).size(24))
            .padding(16)
            .width(Fill)
            .height(Fill);

        row![sidebar, content].into()
    }

    pub fn theme(&self) -> Theme {
        Theme::Dark
    }
}
```

### Task 3: Release workflow and README build section

**Files:**
- Create: `.github/workflows/release.yml`
- Modify: `README.md` (append a Build section)

**Interfaces:**
- Consumes: the crate from Task 1 (binary name `osu-tablet-optimizer`).
- Produces: on a `v*` tag, a GitHub release named after the tag with assets `osu-tablet-optimizer-windows-x64.exe`, `osu-tablet-optimizer-linux-x64.tar.gz` and `osu-tablet-optimizer-macos-arm64.tar.gz`. Tags containing `-` become pre-releases.

- [ ] **Step 1: Create `.github/workflows/release.yml`**

```yaml
name: Release

on:
  push:
    tags: ['v*']

permissions:
  contents: write

jobs:
  build:
    strategy:
      matrix:
        include:
          - os: windows-latest
            target: windows-x64
          - os: ubuntu-latest
            target: linux-x64
          - os: macos-latest
            target: macos-arm64
    runs-on: ${{ matrix.os }}
    env:
      ASSET: osu-tablet-optimizer-${{ matrix.target }}
    steps:
      - uses: actions/checkout@v5
      - uses: dtolnay/rust-toolchain@stable
      - run: cargo build --release --locked
      - name: Package
        shell: bash
        run: |
          if [ "$RUNNER_OS" = "Windows" ]; then
            mv target/release/osu-tablet-optimizer.exe "$ASSET.exe"
          else
            tar -czf "$ASSET.tar.gz" -C target/release osu-tablet-optimizer
          fi
      - uses: actions/upload-artifact@v4
        with:
          name: ${{ env.ASSET }}
          path: ${{ env.ASSET }}.*

  publish:
    needs: build
    runs-on: ubuntu-latest
    steps:
      - uses: actions/download-artifact@v4
        with:
          path: dist
          merge-multiple: true
      - name: Create release
        env:
          GH_TOKEN: ${{ github.token }}
        run: |
          flags="--generate-notes"
          case "$GITHUB_REF_NAME" in *-*) flags="$flags --prerelease" ;; esac
          gh release create "$GITHUB_REF_NAME" dist/* --repo "$GITHUB_REPOSITORY" $flags
```

`macos-latest` is Apple silicon. `ponytail:` Intel Macs aren't built; add a `macos-13` / `macos-x64` matrix row if someone needs it.
